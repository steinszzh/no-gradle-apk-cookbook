# 06 · 排错速查

按报错查。每条都来自实际踩过的坑，不是推测。

| 报错 / 现象 | 原因 | 修法 |
|---|---|---|
| `insufficient memory for the Java Runtime Environment` | `ulimit -v` 限制虚拟地址空间，JVM 默认堆预留过大 | 用 `JAVA_TOOL_OPTIONS` **收窄**堆（`-Xmx700m` 等全套），别加大；见 [02](02-环境坑.md) |
| `javac: command not found`，但 `java` 有 | 只装了 JRE | 装用户级 JDK 17，不要动系统包 |
| `cannot find symbol metafactory` / `Fatal Error: Unable to find method metafactory` | `-bootclasspath android.jar` 下 lambda 缺 `LambdaMetafactory` | 改匿名内部类（如 `ValueCallback`），不用 lambda |
| `aapt2 compile` 找不到输出目录 | `-o` 目录不存在 | 先 `mkdir -p` |
| `aapt2 link` 报资源引用 / style 找不到 | `res/` 写错，或 `@style` / `@color` 定义在别处 | 检查 `res/values/`，确认 `-I android.jar` |
| `R.layout.xxx` 编译不过 | `R.java` 没一起交给 javac | `aapt2 link --java out/gen`，把 `out/gen/**/*.java` 加入 javac 输入 |
| `dl.google.com` 超时 / sdkmanager 卡住 | 网络不可达 | 腾讯 / TUNA 镜像按文件名直连，见 [00](00-工具链与镜像.md) |
| 腾讯镜像目录页 400 | 镜像不提供目录列表 | 正常，直接 `curl -o` 具体 zip 文件名 |
| build-tools 解压后是 `android-14` | 镜像包顶层目录名与版本号不一致 | 重命名为 `34.0.0` |
| `tar` 刷 `Cannot utime` | 改不了时间戳，属元数据权限 | 忽略，`javac -version` 能跑即可 |
| `entry "key" does not contain a key` | keystore 别名不对 | `keytool -list -keystore release.jks` 查别名，对齐 `KS_ALIAS` |
| `apksigner verify` 不通过 | 签名后又改了 APK，或没 `zipalign` | 顺序固定：加 dex → `zipalign` → 签名，之后不再动文件 |
| Android 11+ 安装失败 | 未做 4 字节对齐或只用了 v1 签名 | `zipalign -p 4` 前置；v1+v2+v3 同开 |
| 安装报「解析包时出现问题」 | `minSdk` 高于设备、Manifest 缺 `exported`、或签名方案不匹配 | 先跑 `verify.sh` 看 badging 与验签 |
| `INSTALL_FAILED_UPDATE_INCOMPATIBLE` | 覆盖安装换了签名 | 复用同一 keystore，或先卸载旧版 |
| 覆盖安装仍装的是旧代码 | `versionCode` 没递增 | 每次出包传 `VERSION_CODE=+1` |
| 启动瞬间白闪 | `windowBackground` 是默认白 | 主题里设成页面主色 |
| 系统深色下页面发灰 / 反色 | Force Dark / algorithmic darkening | API33 关 `setAlgorithmicDarkeningAllowed`，API29–32 关 `FORCE_DARK_OFF`，页面加 `color-scheme` |
| 状态栏图标看不见 | 深色背景上加了 `LIGHT_STATUS_BAR` | 深色底去掉该 flag |
| 系统字体调大后布局散架 | WebView 跟随系统字体缩放 | `setTextZoom(100)` |
| 返回键直接退出、页面弹层关不掉 | `evaluateJavascript` 返回值带一层 JSON 引号 | 判断 `"\"1\""`，不是 `"1"` |
| 杀进程后数据丢失 | `file://` 下 localStorage 不落地 | `@JavascriptInterface` 桥到 SharedPreferences，前端三级兜底 |
| 点了喇叭没声音 | 系统 TTS 缺语音数据，`setLanguage` 返回 `LANG_MISSING_DATA` | 内置音频，见 [04](04-音频与素材.md) |
| 音频错位 / 读不到 | 文件名序号与数据数组索引不一致 | 用同一脚本生成 `data.js` 与 `aNNNN.mp3` |
| `npm install` OOM / WASM 分配失败 | 受限内存下重装依赖 | 依赖常已存在，设 `NODE_PATH` 直接跑 jsdom；jsdom `getBoundingClientRect()` 恒 0，别测尺寸 |
| 页面外链资源加载失败 | 离线包里引用了 CDN 字体 / 图标 | 全部本地化，加一条扫描 `http(s)://` 的检查 |
| 浏览器起不来，无法截图验收 | 无头 Chromium 被沙箱 / snap 权限挡住 | 别硬刚，用 jsdom 跑交互断言 + 真机人工看一眼 |

## 三条最容易被忽略的顺序 / 状态约束

1. **`zipalign` 必须在 `apksigner` 之前**，签名后任何写入都会破坏 v2/v3。
2. **`minSdk` / `targetSdk` / `--min-api` / `--min-sdk-version` 四处要一致**，不一致会在安装或运行时才暴露。
3. **keystore 属于长期状态**，不是构建产物；它不该在 `out/` 里，更不该在仓库里。
