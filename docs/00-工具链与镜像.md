# 00 · 工具链与镜像

手工链路只需要三样东西，总共约 690MB：

| 组件 | 作用 | 本教程使用 |
|---|---|---|
| Android SDK Build Tools | `aapt2` / `d8` / `zipalign` / `apksigner` | `34.0.0` |
| Android Platform | `android.jar`（编译时的框架类） | `android-35` |
| JDK | `javac` / `keytool`，以及跑上面那些 Java 工具 | Temurin JDK 17 |

**不需要**：Android Studio、Gradle、AndroidX、`sdkmanager`（可选）、root 权限、Kotlin 编译器。另外系统要有 `zip`、`unzip`、`curl`（几乎都有）。

## 一、装到哪儿：固定用户目录

```bash
$HOME/.local/share/android-toolchain/
├── jdk17/
├── sdk/
│   ├── build-tools/34.0.0/
│   └── platforms/android-35/
└── dl/                      # 下载缓存
```

这个选择看着琐碎，其实是最容易踩的坑之一：**别把 690MB 工具链放进按日期命名的工作区**。很多 AI 助手 / 临时项目目录每次会话都会换，`sdk/` 跟着一起消失，下次又得重下一遍。放在用户级固定目录，一次装完跨项目、跨会话复用。

用环境变量 `TOOLCHAIN` 可以覆盖路径（`build_apk.sh`、`install-toolchain.sh`、`verify.sh` 都认）。

## 二、镜像源：目录列表 400 不代表取不到

在受限网络里 `dl.google.com` 通常不可达。可用的是：

```bash
B=https://mirrors.cloud.tencent.com/AndroidSDK          # Android SDK 组件
T=https://mirrors.tuna.tsinghua.edu.cn/Adoptium/17/jdk/x64/linux   # Temurin JDK17
```

四个直连文件名：

| 文件 | 内容 | 解压后目录名 |
|---|---|---|
| `build-tools_r34-linux.zip` | Build Tools 34.0.0 | `android-14`（**要重命名成 `34.0.0`**） |
| `platform-35_r02.zip` | Platform android-35 | `android-35` |
| `commandlinetools-linux-11076708_latest.zip` | 可选：`sdkmanager` | `cmdline-tools` |
| `OpenJDK17U-jdk_x64_linux_hotspot_17.0.21_9.tar.gz` | JDK 17.0.21+9 | `jdk-17.0.21+9`（重命名 `jdk17`） |

⚠️ **腾讯镜像的目录列表接口返回 400，但按文件名直连能正常下载**。不要因为打开目录页报错就以为镜像挂了，直接 `curl -o` 具体文件名即可。

另外 `build-tools` 包解压出来的顶层目录叫 `android-14`，而工具按版本号找路径，必须改名 `34.0.0`，否则 `sdkmanager` 之类的工具认不出来。

## 三、一条命令装好（幂等）

```bash
bash scripts/install-toolchain.sh
# 慢网络可走本地代理：
APK_PROXY=http://127.0.0.1:7890 bash scripts/install-toolchain.sh
```

脚本逻辑：

1. 检查 `aapt2` / `android.jar` / `javac` 三件套，齐全就**立刻退出，不下载任何东西**；
2. 缺哪个补哪个，`curl -C -` 支持断点续传、`--retry 5`；
3. 解压、改名、就位；
4. 最后打印 `javac -version` 作为验收。

本机实测（已装状态）：

```
✅ 工具链已就绪：$HOME/.local/share/android-toolchain（无需下载）
javac 17.0.21
```

### 两个正常现象

- **JDK 解压时 `tar` 会刷一屏 `Cannot utime: Operation not permitted`** —— 只是改不了文件时间戳，文件本身完整，`javac -version` 能跑就没事。脚本里已经把这路输出吞掉并容错。
- `curl` 走代理时如果报 `speed-limit`，是慢链路触发了 `--speed-limit 3000`；加大重试次数或换节点即可。

## 四、装完自检

```bash
T=${TOOLCHAIN:-$HOME/.local/share/android-toolchain}
ls "$T"/sdk/build-tools/*/aapt2
ls "$T"/sdk/platforms/*/android.jar
"$T"/jdk17/bin/javac -version
```

三行都有输出就可以进入 [01 · 六步链](01-六步链.md)。

> 若想用官方 `sdkmanager` 管理组件，可以额外解压 `commandlinetools-*`，再
> `sdkmanager --sdk_root=... "platforms;android-35" "build-tools;34.0.0"`。
> 但它自己也要走代理、要接受 licenses，在受限环境里比直连文件名麻烦得多，
> 本教程不依赖它。
