# 04 · 音频与素材

手工链的好处之一是「包里有什么」完全由你决定。这一章讲怎么在不引入第三方 SDK、不依赖用户设备环境的前提下把声音和素材做进去。

## 1 · 别指望系统 TTS 引擎

一个很典型的「用户反馈点了没声音」：应用调 `TextToSpeech.speak()`，代码没报错，但国产 ROM 大多没预装英文语音数据，

```java
tts.setLanguage(Locale.US);   // 返回 LANG_MISSING_DATA
```

此时是**静默失败**。让用户自己去装 30–60MB 的语音引擎是很差的体验，正确做法是把音频直接打进 `assets/`。

## 2 · 用 edge-tts 批量合成，ffmpeg 裁静音

```bash
pip install edge-tts            # 慢网络走本地代理

# 逐条合成（示意，实际用 Python 批量并发）
edge-tts --voice en-US-AriaNeural --rate=-12% --text "example" --write-media raw.mp3

# 裁掉首尾静音 + 压成单声道小体积
ffmpeg -y -i raw.mp3 \
  -af "silenceremove=start_periods=1:start_threshold=-50dB:start_silence=0.04,areverse,silenceremove=start_periods=1:start_threshold=-50dB:start_silence=0.06,areverse" \
  -ac 1 -ar 22050 -c:a libmp3lame -b:a 32k -write_xing 1 a0000.mp3
```

`areverse` 前后各来一次，是为了同时裁掉**头部和尾部**的静音（单次 `silenceremove` 只能处理一端）。

命名与索引必须严格对齐：数据数组第 N 条 ↔ `assets/audio/aNNNN.mp3`。前端按 `pad4(idx)` 拼路径，一旦错位就是整批读错，建议用一个脚本同时生成 `data.js` 和音频文件，别手工维护两份顺序。

实测参考量级：697 条、平均 3.5KB/条、合计约 2.4MB，5 路并发约 10 分钟；纯 WebView 壳 APK 会从 ~370KB 涨到 3MB 左右。还想再省一半可以换 opus/ogg 24kbps，Chromium 内核的 WebView 支持。

## 3 · 前端播放的兜底顺序

```js
function speak(idx) {
  var a = new Audio('audio/a' + pad4(idx) + '.mp3');
  a.play().catch(function () {
    // 内置音频被拒（自动播放策略等）才退回系统能力
    try { speechSynthesis.speak(new SpeechSynthesisUtterance(words[idx])); } catch (e) {}
  });
}
```

`<audio src="audio/a0000.mp3">` 直接读 `file:///android_asset/audio/...` 即可，**不需要**开 `setAllowFileAccessFromFileURLs`（那个开关是跨域用的，开了反而扩大攻击面）。

自动播放场景在 Java 侧设 `s.setMediaPlaybackRequiresUserGesture(false)`；更稳妥的做法仍是让首次播放由用户点击触发。

## 4 · 环境音 / 音效也可以纯代码合成

不是所有声音都要真人录音。雨声、灯管嗡鸣、电梯叮、钥匙落地脆响、救护车渐近，都能用 numpy 直接生成波形再混音：

```python
import numpy as np
sr = 44100
t = np.arange(sr * 2) / sr
rain = np.random.default_rng(3).normal(0, .12, len(t))       # 白噪底
hum  = .05 * np.sin(2 * np.pi * 100 * t)                      # 50/60Hz 工频嗡鸣
```

配音（在线 TTS）、音效（代码合成）、环境底噪（代码合成）三层叠好导出一个 `soundtrack.wav`，再交给 `apksigner` 之前的打包阶段或直接随 APK 附带。这样「画面 100% 代码生成」的项目，声音也能做到几乎全代码。

⚠️ 口径提醒：`edge-tts` 是在线神经语音服务，属于外部模型服务，宣传时别写成「零模型 / 全离线」；准确说法是「画面与音效由代码生成，对白配音使用在线 TTS」。

## 5 · 图片与字体

- **不随包分发外部图片素材**。示例图标由脚本（PIL）画出来，4 倍超采样后缩小到五档 mipmap，见 [03 · WebView 壳适配](03-WebView壳适配.md)。
- **中文字体别打包进 APK**（一套 CJK 字体动辄十几 MB）。用系统字体：`font-family: system-ui, "Noto Sans CJK SC", sans-serif`，让 WebView 走系统 fallback。
- 若确实需要特定字体，只放子集化的 woff2，并用 `@font-face` 引用 `file:///android_asset/fonts/...`。
- 页面里禁用外链资源：CDN 上的字体 / 图标在离线应用里必然加载失败。CI 里可以加一条「扫描 `http(s)://` 引用」的检查，本仓库的 `tests/smoke.js` 已经带了这一条。
