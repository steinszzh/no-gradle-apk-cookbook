# 02 · 环境坑

这一章是整份教程最不「标准」、也最有用的部分。这些坑在官方文档里查不到，在普通 Android 教程里更不会提，但在受限 Linux / 容器 / 沙箱环境里几乎必然遇到。

## 1 · `ulimit -v 4G`：要「收窄」JVM 堆，不是加大

很多机器（尤其是受限 shell、CI runner、沙箱）设了虚拟内存上限：

```bash
ulimit -v        # 4294967296 → 4G
```

`aapt2`、`d8`、`apksigner` 都是 Java 工具，默认堆会按宿主机内存去预留虚拟地址空间，一启动就：

```
Error occurred during initialization of VM
Could not reserve enough space for object heap
insufficient memory for the Java Runtime Environment
```

**关键认知**：网上所有同类内存文章都在教「把 Gradle 堆加大」（`-Xmx4g`），在这里方向完全相反 —— 上限是虚拟地址空间，堆越大越起不来。要显式把每个 JVM 参数都压小：

```bash
export JAVA_TOOL_OPTIONS="-Xmx700m -Xms64m \
  -XX:MaxMetaspaceSize=192m -XX:CompressedClassSpaceSize=96m \
  -XX:ReservedCodeCacheSize=96m -XX:MaxDirectMemorySize=128m"
```

用 `JAVA_TOOL_OPTIONS` 而不是给每个命令单独加参数，是因为 `aapt2` / `d8` / `apksigner` 的启动脚本各自会再拉起 JVM，环境变量能一次覆盖全部。脚本里已经内置，不需要自己设。

副作用是每次都会打印一行 `Picked up JAVA_TOOL_OPTIONS: ...`，属正常。

## 2 · 系统只有 JRE，没有 javac

```bash
javac -version     # command not found
java -version      # 有
```

Ubuntu 上只装 `default-jre-headless` 就会这样，而 `aapt2` / `d8` 只需要 `java`，所以你甚至可能一直没发现少了编译器，直到第 3 步。

不要试图改系统包（受限环境里往往没有 sudo / root）。装一份用户级 JDK 17 到固定目录即可，见 [00 · 工具链与镜像](00-工具链与镜像.md)。用 JDK 17 而不是系统自带的 JRE，也顺带解决了 `-source 8 -target 8` 的兼容问题。

## 3 · `dl.google.com` 不可达

国内网络 / 内网环境里，`dl.google.com`、`cdn.playwright.dev` 常常超时，直接照官方 `sdkmanager` 流程会卡死在下载。

解决：按文件名从腾讯 AndroidSDK 镜像 + 清华 TUNA Adoptium 镜像直连取包，**不依赖目录列表和 sdkmanager**。详见 [00 · 工具链与镜像](00-工具链与镜像.md)。

慢链路再叠加本地代理：`APK_PROXY=http://127.0.0.1:7890 bash scripts/install-toolchain.sh`。

## 4 · javac 报 `cannot find symbol metafactory`

本仓库实跑时抓到的真问题：

```
error: cannot find symbol
  symbol: method metafactory(Lookup,String,MethodType,...)
  location: interface LambdaMetafactory
Fatal Error: Unable to find method metafactory
```

原因：第 3 步用 `-bootclasspath android.jar` 编译，`android.jar` 里没有完整的 `java.lang.invoke` 引导类，而 lambda 需要 `invokedynamic` + `LambdaMetafactory`。

修法：**改成匿名内部类**。示例里返回键的回调就是：

```java
web.evaluateJavascript("window.__back && window.__back()", new ValueCallback<String>() {
    @Override public void onReceiveValue(String value) {
        if (!"\"1\"".equals(value)) finish();
    }
});
```

Kotlin / 依赖 AndroidX 的项目不会遇到，因为它们有自己的编译链；纯手工链会。

## 5 · 跑不了浏览器时怎么验证前端

受限环境里 Chromium 常常起不来（snap 权限、`unshare` 被禁、无 GPU）。别在截图上耗时间，用 jsdom 跑交互逻辑：

```bash
NODE_PATH=<jsdom 所在 node_modules> node tests/smoke.js
```

套路：读 `assets/index.html` → `new JSDOM(html, {runScripts:'dangerously', beforeParse})` → 在 `beforeParse` 里注入 `NativeStore` 假桥 → 用 `window.MouseEvent('click')` 点按钮 → 断言 DOM 文本与持久化调用。本仓库 12 条断言覆盖了计数、清零、面板、返回键、无外链资源。

jsdom 没有布局引擎：`getBoundingClientRect()` 恒为 0，CSS 尺寸问题只能靠读样式算，不要指望它替代真机视觉检查。

## 6 · 其他零散但高频的

| 现象 | 原因 / 处理 |
|---|---|
| `aapt2 compile` 报找不到输出目录 | `-o` 指向的目录必须已存在，先 `mkdir -p` |
| `apksigner` 报 `entry "key" does not contain a key` | keystore 别名不对，`keytool -list -keystore x.jks` 查 |
| 安装时「解析包时出现问题」 | 多数是 `minSdk` / 签名方案 / 未 `zipalign` 的组合问题，先跑 `verify.sh` |
| 腾讯镜像目录页返回 400 | 正常，按文件名直连能取到 |
| JDK 解压刷 `Cannot utime` | 时间戳元数据权限问题，文件完整，`javac -version` 能跑即可 |
| 同包名覆盖安装失败 | 换了 keystore 或 `versionCode` 没递增，见 [05 · 验签与交付](05-验签与交付.md) |
| `npm install` 因 WASM 分配 OOM | 依赖往往其实已装好，设 `NODE_PATH` 直接跑即可，别重装 |

更多按报错查的条目见 [06 · 排错速查](06-排错速查.md)。
